# QA-тесты сайта (Python + Playwright, Chromium)

pip install playwright && python -m playwright install chromium
npm i --no-save axe-core

qa1.py - все страницы на 5 размерах экрана, ошибки JS, переполнения, доступность (axe).
         Запуск на сборке без Supabase: npm run build:artifact && npx vite preview --outDir dist-artifact --port 4173
qa2.py - 31 пользовательский сценарий (меню, язык, лента, пасхалки, музыка, мерч, тур, анонсы, организаторы, навигация).
qa3.py - стресс, утечки памяти, ресайз, reduced motion, кривые данные из админки, края админки.
         qa2 и qa3 запускаются на тестовой сборке с поддельной базой: npm run test:admin (порт 4174, поменяйте U в скрипте).

Примечание: axe ругается на контраст текстов поверх WebGL-фона (мерч), потому что не видит холст.
Замер по реальным пикселям даёт контраст 10:1 и выше, это ложное срабатывание.

swipe.py - свайпы пальцем на телефоне (короткий свайп держит главу, длинный доводит до следующей).
snap3.py - доводка колесом: пауза держит главу, выезд вперёд/назад доводит до соседней.
Тесты ждут, пока лента успокоится: в headless-браузере WebGL рисуется программно и кадров мало.
inter.py - новые взаимодействия (буквы обложки, зачёркивание, значок, IT, стразы, звонок, синглы, пасхалка). org.py - пропуск, пресс-кит, копирование, финал.
prod.py - страница товара: переход с мерча, кнопка «Купить» ведёт в официальный магазин, похожие товары, панель на телефоне.
legal.py - баннер cookie, плеер только после согласия, документы, отсутствие запросов к Google, доступность. Остальные тесты заранее ставят согласие, чтобы баннер им не мешал.

Жёсткий прогон:
hard1.py main|extra - все страницы RU/EN на 6 экранах: ошибки, предупреждения, мусор в тексте, переполнения, картинки без alt.
hard2.py - доступность всех страниц, обход всех внутренних ссылок, фокус с клавиатуры.
kbd.py - видимая рамка фокуса у каждого элемента.
words_all.py - нет слов, разорванных посередине, на 5 ширинах и 2 языках.
overflow_all.py - нет горизонтального переполнения на 320/768/1024/1440.
call.py - таймер и печать вопроса в звонке.
ios.py - телефон в режиме iPhone: после свайпов и тапов лента не двигается сама, скачок высоты (адресная строка iOS) не сдвигает ленту; на десктопе доводка колесом осталась.
(swipe.py удалён: на сенсорных экранах доводки больше нет, её заменил ios.py)
ios2.py - эмуляция iPhone: нет Lenis, буквы обложки не застревают, меню не сдвигает ленту, стразы не сыплются от пальца, нет размытых подложек, лента не двигается сама.
deskmenu.py - десктоп: колесо по открытому меню не сдвигает ленту, после закрытия прокрутка работает.
iphone.py - по скриншотам с iPhone: билеты тура компактные, шапка с подложкой, меню влезает на 320/360/390, пропуск без автоклавиатуры и без полосы автозаполнения, ячейки видны при клавиатуре, буквы обложки на месте.
music2.py / still.py - музыка: альбомы целиком, подсказка «нажми play», пластинка стоит в покое и крутится при игре.
logo.py - логотип: загрузка, лёгкая версия на телефоне, шапка без инверсии, желейная встряска по клику.
fontshots.py - шрифты эпох загружены, скриншоты глав.
music3.py - вся дискография в списке (76 песен), Яндекс Музыка и Spotify, подсказка не наезжает на название.
fling.py - телефон: каждый флик переводит ровно на одну главу (нативная привязка прокрутки). stage1.py - заставка, курсор, логотип к первому слайду, плеер не прыгает.
fit.py - телефоны 320/375/390: в каждой главе всё помещается в экран и фото не ложится на текст. chshots.py W H tag - скриншоты всех глав.
edges.py / edges_m.py - фото и карточки с учётом поворота не выходят за левый и правый край своей главы (иначе на стыке глав разрыв). navclear.py - фото не заходят под шапку.
video.py - страница «Видео»: клипы, плеер только после согласия, без запросов к YouTube до согласия, на фото нет надписей. menufit.py - мобильное меню из 7 пунктов помещается.
admin2.py - новые поля админки: раздел «Видео» (ссылка YouTube -> ID, клип появляется на сайте), «Второе фото», обложки альбомов и треков.
upload.py - сжатие фото при загрузке в админке (PNG 15 МБ -> WebP ~0.8 МБ), поля кадров фотобудки. newsfield.py - поле «Фото к анонсу».
missperf.py / missab2.py - замер кадров на главе MISS и A/B вариантов надписи (в эмуляторе шумно, смотреть медианы).
sparks.py - блёстки MISS: появляются, без фильтров, лимит одновременных. inter.py обновлён под живой логотип и обложки «Сейчас».
intro_timing.py / mpre.py - логотип скрыт до сигнала заставки и стартует вместе с подъёмом шторки; заставка уходит за ~1 с на телефоне.
scrollreset.py - новая страница открывается сверху (компьютер и телефон, из меню и подвала); закрытие меню на той же странице сохраняет позицию. sister2.py - большое фото «Младшей сестры» без фильтра.
musicfit.py - музыка на компьютере: страница не прокручивается, колесо над списком крутит только список, плеер целиком в экране (6 размеров).
hint2.py / hint3.py - подсказка «листай вниз»: до 3 показов по ~4.5 с с паузой ~10 с, после первой прокрутки исчезает навсегда (журнал времени пишет сама страница).
music4.py - музыка: колесо над пластинкой/названием прокручивает список, оповещение «Где будем слушать?» включает выбранный сервис.
ios5.py - телефон: обложка без фильтров (iOS), MISS влезает, «Младшая сестра» показывает второе фото, меню с документами, новые «Анонсы».
glres.py - разрешение фона (телефон ~0.8 плотности, компьютер ~0.75 с потолком 1.6 млн px). glstall.py - на медленном устройстве адаптивное качество за 1-2 с снижает разрешение до нижней границы.
credit.py - подпись «Designed by cookiekiller»: финал плёнки, подвал (тёмный/светлый), вход и панель админки, телефон.
