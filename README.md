# дора - эры

Фан-сайт в подарок Доре. React + Vite, GSAP + ScrollTrigger, Lenis, собственный WebGL-шейдер эр, Supabase (этап 2), Vercel.

## Запуск
npm install
npm run dev

## Деплой на Vercel
Framework preset: Vite. Build: `npm run build`. Output: `dist`. Переменные окружения из `.env.example`.

## Где что лежит
- `src/data/eras.js` - шесть эр, тексты RU/EN, треки и Spotify ID. Чтобы трек играл прямо на сайте, впишите его ID в поле `spotify`.
- `src/gl/shader.js` - фон: тетрадь, ксерокс, пузыри, хром, боке, снег. Переходы между эрами идут волной шума.
- `src/pages/Music.jsx` - плеер через Spotify iFrame API; визуалайзер синхронизирован с позицией трека и его BPM.
- `src/pages/Organizers.jsx` - блок организаторов. Сейчас код 1111 проверяется в браузере (временно). Этап 2: файлы в приватный bucket Supabase, см. `supabase/schema.sql`.

## Мерч и соцсети
- `src/data/merch.js` - товары официального магазина realdora.store, ссылки ведут в магазин. Иллюстрации наши (`src/components/MerchArt.jsx`), фото товаров можно взять у команды.
- `src/data/links.js` - соцсети, тур, контакты букинга. YouTube-канал пока не добавлен.

## Админка (/admin)
Редактируются все блоки: главы на плёнке (тексты, кнопки, треки и Spotify-ссылки), вырезки, тур, анонсы, мерч, соцсети, ссылки и контакты, закрытый блок организаторов (код, промо-фото, райдеры).
Без Supabase сайт работает на значениях по умолчанию из `src/data/`, а админка показывает инструкцию по подключению.

Подключение:
1. Выполнить `supabase/schema.sql` в SQL Editor.
2. Authentication → Users → Add user, затем `insert into admins (user_id) values ('id');`
3. Выключить регистрацию новых пользователей.
4. `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в Vercel, пересобрать.

Код организаторов проверяет серверная функция `org_kit`, фото и документы приходят только после верного кода.
Файлы лежат в публичном bucket `media` под случайными именами: ссылку нельзя угадать, но её можно переслать.

Автотест админки на поддельной базе: `npm run test:admin`, затем открыть http://localhost:4174/#/admin (пароль test).

## Правовые документы
Страницы /legal, /privacy, /cookies, /terms (src/pages/Legal.jsx), баннер cookie (src/components/ConsentBanner.jsx).
Данные владельца сайта заполняются в админке: «Ссылки, контакты и владелец». Пока они пустые, на страницах видны жёлтые пометки.
Шрифты подключены локально (@fontsource), без запросов к Google. Плеер Spotify загружается только после согласия посетителя.
Документы составлены как шаблон под фактическую работу сайта; перед запуском их стоит показать юристу.

## Фото, тур, анонсы
- `public/photos/` + `src/data/photos.js` - официальные фото из пресс-кита. Вырезка сама превращает фото в газетный растр или журнальный глянец; пока фото нет, стоит силуэт-заглушка.
- `src/data/tour.js` - даты тура (собраны с открытых афиш, сверить с band.link/dora_2026). Прошедшие концерты определяются автоматически по сегодняшней дате.
- `src/data/news.js` - анонсы для страницы «Дорин вестник».

## Spotify-плеер
В превью на claude.ai внешние скрипты Spotify заблокированы политикой безопасности, поэтому там плеер не играет.
После деплоя на Vercel плеер и синхронизация визуалайзера работают.

## Лента на телефонах
На сенсорных устройствах доводка глав выключена: на iOS после отпускания пальца страница едет по инерции,
и программная доводка «сама свайпала» ленту. Паузы на главах остаются - они заложены в механику ленты.
Высота ленты на телефонах в svh, чтобы не прыгать от прячущейся адресной строки iOS.
На тач-экранах: прокрутка нативная (Lenis не запускается), лента следует за пальцем почти без сглаживания,
эффекты для курсора (буквы обложки, стразы, разгон значка) реагируют только на мышь,
размытые подложки выключены, меню блокирует прокрутку страницы через фиксацию body.

## Пасхалки

## Устройство кода

```
src/pages/home/
  Home.jsx          сборка главной: обложка, главы, финал
  useTape.js        горизонтальная лента с паузами на главах, store эпохи, появление глав
  snapper.js        доводка ленты колесом (на тач-экранах выключена)
  tape.js           математика ленты: переезды, паузы, точки доводки
  intros.js         анимации появления глав
  Cover.jsx         живой логотип
  ScrollHint.jsx    напоминалка про скролл
  shared.jsx        кнопка главы, фото главы, подпись дат
  chapters/         по файлу на главу и финал
src/data/eras.js    главы и полная дискография одной структурой
tools/
  cssdups.mjs       поиск повторно определённых селекторов в CSS
  cssmerge.mjs      слияние повторов в первое определение
  style-snapshot.py слепок вычисленных стилей всех страниц (до/после рефакторинга)
  style-diff.py     сравнение двух слепков
```

Стили: base.css (основа, шапка, меню, курсор), home.css (лента главной), chapters.css (композиции глав,
десктоп и телефон), pages.css (остальные страницы и рамки фото EraPhoto).
Инструменты: tools/cssedit.mjs (точечная правка правила по селектору), tools/cssmove.mjs (перенос правил между файлами).

Фото и обложки в админке:
- «Фото глав» -> у «Младшей сестры» и финала есть «Второе фото».
- «Главы» -> «Обложка альбома» (центр пластинки на странице музыки).
- «Главы» -> треки -> «Обложка трека» (блок «Сейчас» и центр пластинки).
Пока ничего не загружено, стоят заглушки в цветах эпохи.

Правило для CSS: не дописывать переопределения в конец файла, а править исходное правило.
Проверка: `node tools/cssdups.mjs` должен показывать 0 повторных селекторов.
